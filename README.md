 * **Base URL:** https://mustafatemur.github.io/privacy-policies/

## 📌 Compliance & Maintenance Notes
 * **Data Practices:** Every HTML document explicitly details what device-specific permissions are requested (e.g., Camera for QR scanning, Camera/Flashlight for TACTİQ, Audio for Sonic Scope) and clarifies that no unauthorized personal data is harvested.
 * **Updates:** Whenever an application's permission model or third-party SDK integration changes, the respective HTML file in this repository is updated immediately.
 * **Hosting Guarantee:** Utilizing GitHub Pages ensures high availability and 100% uptime for Google Play review crawlers.
